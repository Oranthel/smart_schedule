## 关键决策摘要

1. **优先级**（高→低）：取消/调课规则 > 硬性固定事项(课程/会议/截止/考试/医疗/不可移动标记) > 临时活动 > 普通基础作息(含睡眠/用餐) > 灵活任务 > 可选事项(ANYTIME)。
2. **睡眠/用餐**：作为普通基础作息，**可被用户添加的临时活动挤占**（次日规则恢复）；AI 主动调度仍不得压缩睡眠或将灵活任务排入睡眠段。
3. **AI 架构**：端侧规则引擎（调度/冲突/休息/精度，确定性可解释）+ 云端 LLM（仅 NL 解析与 OCR 结构化，带置信度），数据最小化。
4. **技术栈**：Android 原生（Kotlin + Jetpack Compose）；备选 React Native（Bare Workflow）。不推荐 Taro 小程序。
5. **版本拆分**：v1.0 核心闭环（6–8 周）→ v1.1（OCR/月视图/闹钟/小组件，4–6 周）→ v1.2（年视图/模式调优，4 周）。
