# 本机 Android 开发环境配置指南（Windows 11）

> 配套 v1.0 开发。本文归档计划 Part A，供你按步骤安装配置。结论先行：**装 Android Studio 基本就齐了**（自带 JDK 与 SDK Manager），单独装 JDK 21 只为命令行构建。
> 沙箱限制：我的 Shell 网络与系统路径受限，**Android Studio 的 GUI 构建由你在本机执行**；我负责写代码与单测。

---

## 一、为什么要配置这些组件

| 组件 | 作用 | 为什么必需 |
|---|---|---|
| **JDK 17+**（推荐 21 LTS） | 运行 Gradle、编译 Kotlin/Java | Gradle 本身是 JVM 程序；Android Gradle Plugin(AGP) 8.x/9.x 强制要求 JDK 17+，否则报 `AGP requires Java 17` |
| **Android SDK** | 提供 Android 平台 API、build-tools、platform-tools(adb)、emulator | 编译 APK、连真机/模拟器都依赖它；AGP 调 build-tools 打包 |
| **Gradle（wrapper）** | 构建系统：编译、依赖管理、打包 APK、跑测试 | Android 工程标准构建工具；wrapper 自动下载指定版本，无需全局安装 |
| **Android Studio** | IDE：编辑器+调试+可视化+SDK Manager+模拟器 | 一站式环境，自带 JBR(JDK)，是获得完整工具链最简单的方式 |

版本基线（2026 稳定，实现时钉死）：
- AGP 8.7+ / Gradle 8.9+ / Kotlin 2.0+ / JDK 17（推荐 21 LTS）/ compileSdk & targetSdk 35 / minSdk 26。

## 二、需要 Docker 吗？

**不需要。** Docker 用于服务端/CI 容器化隔离，本地 Android 应用开发用 JDK+SDK+Gradle+Android Studio 这套原生工具链，二者无关。后续做 CI 自动构建可考虑 Docker，本地开发不引入。

## 三、下载地址（官网 + 国内镜像，二选一）

> 国内强烈走镜像，否则 `dl.google.com` / `services.gradle.org` 下载极慢或中断。

**Android Studio 安装包**
- 官网：https://developer.android.com/studio （国内访问慢）
- 清华镜像（推荐）：https://mirrors.tuna.tsinghua.edu.cn/AndroidStudio/
- 华为镜像：https://mirrors.huaweicloud.com/androidstudio/

**JDK 21（Temurin / Eclipse Adoptium，可选——Android Studio 自带 JBR）**
- 官网：https://adoptium.net/temurin/releases/?version=21
- 华为镜像：https://mirrors.huaweicloud.com/openjdk/
- 微软 OpenJDK：https://learn.microsoft.com/java/openjdk/

## 四、安装步骤（Windows 11）

1. 下载 Android Studio 安装包（走第三节镜像）。文件名形如 `android-studio-2025.3.x-windows.exe`。
2. **路径原则**：安装路径**无中文、无空格**；建议非系统盘，如 `D:\Android\Android Studio`。SDK 单独放 `D:\Android\Sdk`。
3. **以管理员身份运行**安装程序 → 默认组件（Android Studio + Android Virtual Device）→ 选路径 → Install → Finish。
4. 首次启动：`Do not import settings` → `Standard` 安装类型 → 选主题 → 确认 SDK 组件下载 → Finish（此时下载 SDK，走第五节镜像加速）。
5. （可选）单独装 JDK 21 用于命令行构建：装到 `D:\Android\jdk-21`，无中文空格。

## 五、配置国内镜像（关键，否则下载卡死）

**(a) Gradle 分发镜像**（项目级，已在工程 `gradle/wrapper/gradle-wrapper.properties` 预配）：
```
distributionUrl=https\://mirrors.cloud.tencent.com/gradle/gradle-8.9-bin.zip
```

**(b) Maven 依赖镜像**（项目级，已在 `settings.gradle.kts` 预配）：
```
maven { url = uri("https://maven.aliyun.com/repository/google") }
maven { url = uri("https://maven.aliyun.com/repository/central") }
maven { url = uri("https://maven.huaweicloud.com/repository/maven/") }
```

**(c) SDK 下载镜像**（IDE 内一次性设置）：
`File → Settings → Appearance & Behavior → System Settings → Android SDK → SDK Update Sites`，添加：
- 腾讯：https://mirrors.cloud.tencent.com/AndroidSDK/
- 华为：https://mirrors.huaweicloud.com/android-sdk/

**(d) SDK 组件**（SDK Manager 内勾选安装）：
- SDK Platforms：最新稳定版（Android 14 / API 34 或更高）
- SDK Tools：Android SDK Build-Tools、Android SDK Platform-Tools、Android Emulator、Android Emulator hypervisor driver（installer）

## 六、环境变量（命令行构建需要）

- `JAVA_HOME` = `D:\Android\jdk-21`（或 Android Studio 自带 JBR，如 `D:\Android\Android Studio\jbr`）
- `ANDROID_HOME` = `D:\Android\Sdk`
- `PATH` 追加：`%JAVA_HOME%\bin`、`%ANDROID_HOME%\platform-tools`、`%ANDROID_HOME%\cmdline-tools\latest\bin`
- （可选）`GRADLE_USER_HOME` = `D:\Android\.gradle`，把 Gradle 缓存移出 C 盘

## 七、打开本项目并构建

1. Android Studio → `File → Open` → 选 `D:\app` 根目录（含 `settings.gradle.kts`）。
2. 首次打开会生成 Gradle wrapper（若 `gradlew` 缺失，AS 用自带 Gradle；也可在 Terminal 跑 `gradle wrapper --gradle-version 8.9` 生成）。
3. 等 Sync 完成（走镜像，首次下载依赖数分钟）。
4. `Run ▶` 选模拟器或真机 → 应用启动到首页。
5. 命令行构建（可选）：`gradlew :app:assembleDebug`、`gradlew :app:testDebugUnitTest`。

## 八、验证环境就绪

PowerShell 执行（应都有版本输出）：
- `java -version`（≥17，推荐 21）
- `adb version`

Android Studio 新建 Empty Activity 项目能 Sync + Run 到模拟器，即说明工具链完整。

## 九、常见问题

- **`AGP requires Java 17`**：`File → Settings → Build,Execution,Deployment → Build Tools → Gradle`，把 Gradle JDK 选为 17/21（或 AS 自带 JBR）。
- **Sync 超时/下载慢**：确认第五节镜像已配；检查 `gradle-wrapper.properties` 的 `distributionUrl` 是否指向腾讯/阿里。
- **路径含中文/空格导致构建异常**：把工程与 SDK 移到无中文空格路径。
- **模拟器起不来**：BIOS 开虚拟化（Intel VT-x / AMD-V）；装 Android Emulator hypervisor driver。
